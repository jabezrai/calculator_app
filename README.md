# Python Calculator

My first Python project: a simple calculator application built using Python and Tkinter. This project helped me develop my understanding of Python fundamentals and learn how to create a graphical user interface (GUI).

## Features

- Basic arithmetic: Addition, subtraction, multiplication and division.
- Percentage calculations: Converts percentage symbols into division by 100.
- Brackets: Supports brackets for more complex mathematical expressions.
- Previous answer (Ans): Allows the user to reuse the previous calculation result.
- Error handling: Displays an error message when a calculation fails.
- Interactive GUI: Uses Tkinter to create a calculator window with clickable buttons.

1. Make sure Python is installed on your computer.
